# Wizard Academy

Wizard Academy is a TypeScript project designed to practice
advanced TypeScript concepts through a magical academy.

## Features

- Wizard registration
- Generic filtering
- Generic repositories
- Spell management
- Type guards
- Method decorators
- Utility types
- Conditional types
- Academy events

## Technologies

- TypeScript
- Node.js
- Git

## Installation

npm install

## Build

npm run build

## Run

npm start


## Project Structure

- src/types.ts
- src/repository.ts
- src/decorators.ts
- src/services.ts
- src/main.ts
